# Website Laila Koy - Personal Training

Diese Website besteht aus drei HTML-Seiten sowie einem gemeinsamen Stylesheet und Script:

- `index.html` - Startseite
- `ueber-mich.html` - Über mich
- `leistungen.html` - Leistungen und Kontakt
- `style.css` - Design, Farben, Layout und responsive Darstellung
- `script.js` - mobile Navigation und Scroll-Animationen

## Inhaltlicher Stand

Die Seiten sind bereits aufeinander abgestimmt und folgen einem gemeinsamen Konzept:

- **naturverbundenes, motivierendes Personal Training**
- **Outdoor-Fokus**
- **Körpergefühl, Leichtigkeit und individuelle Begleitung**
- **Marathon- und Triathlonbegleitung** als eigener Schwerpunkt
- **Yoga / Pilates Friends Pakete**
- **Vorbereitung auf die Eignungstests der Sporthochschule Köln**

## Was du noch ersetzen solltest

Alle Stellen mit dem Hinweis **"Platzhalter"** sind weiterhin zum Ausfüllen gedacht.

### 1. Kontaktdaten

Bitte ergänze in allen Dateien die finalen Angaben für:

- E-Mail
- Telefon
- Standort
- Instagram

Diese Angaben erscheinen im Footer aller Seiten und zusätzlich im Kontaktbereich von `leistungen.html`.

### 2. Porträtfoto

Sowohl in `index.html` als auch in `ueber-mich.html` ist aktuell noch eine Platzhalterfläche für dein Bild enthalten.

Sobald du ein Foto hast, kannst du den Platzhalter jeweils durch ein Bild ersetzen, zum Beispiel so:

```html
<img src="portraet.jpg" alt="Laila Koy" />
```

Achte darauf, dass das Foto möglichst im **Format 4:5** vorliegt.

### 3. Optional: Zahlen oder Fakten auf der Startseite

Die Startseite wurde bewusst ohne erfundene Kennzahlen aufgebaut. Falls du später echte Werte ergänzen möchtest, könntest du dort zum Beispiel reale Angaben zu Erfahrung, Schwerpunkten oder betreuten Formaten einbauen.

## Dateien lokal testen

Du kannst die Website lokal testen, indem du `index.html` im Browser öffnest.

Am besten liegen dabei alle Dateien im gleichen Ordner:

- `index.html`
- `ueber-mich.html`
- `leistungen.html`
- `style.css`
- `script.js`

## Auf GitHub Pages veröffentlichen

1. Erstelle ein neues Repository auf GitHub.
2. Lade alle Website-Dateien in dieses Repository hoch.
3. Öffne im Repository **Settings -> Pages**.
4. Wähle als Source den Branch `main` und den Ordner `/root`.
5. Speichere die Einstellung.
6. Nach kurzer Zeit ist deine Website über die GitHub-Pages-URL erreichbar.

## Empfohlene Dateistruktur

```text
/
|- index.html
|- ueber-mich.html
|- leistungen.html
|- style.css
|- script.js
|- portraet.jpg   (optional, sobald vorhanden)
```
